## 📖 Descripción

Project Valkyrie es una plataforma SaaS diseñada para crear, administrar y operar personajes virtuales impulsados por Inteligencia Artificial.

Su propósito es centralizar todo el ciclo de vida de un personaje virtual, desde su creación hasta la generación de contenido, permitiendo reutilizar identidades digitales en distintos proyectos y plataformas.

La aplicación está siendo desarrollada con un enfoque profesional, priorizando una arquitectura escalable, mantenible y preparada para producción.

# ⚙️ Instalación

Clonar el repositorio:

```bash
git clone <repository-url>
```

Entrar al proyecto:

```bash
cd project-valkyrie
```

Instalar dependencias:

```bash
npm install
```

Ejecutar el proyecto:

```bash
npm run dev
```
